# Google Play 掲載用の素材と入力内容

Android版は、公開中のサイトをそのまま包む「TWA（Trusted Web Activity）」で作る。
アプリの中身はサイトを読み込むので、問題の追加や修正はサイトを更新するだけで反映される（ストアの再審査は不要）。

## ストアの掲載情報

- **アプリ名（30文字以内）**：かんたん早押しクイズ
- **カテゴリ**：ゲーム ＞ 雑学（Trivia）
- **簡単な説明（80文字以内）**：
  問題文が1文字ずつ流れる早押しクイズ。ひとりで練習も、友だちと対戦もできます。
- **詳しい説明（4000文字以内）**：

```
問題文が1文字ずつ流れていく、本格的な早押しクイズです。
答えがわかった瞬間にボタンを押して、ひらがな4択で1文字ずつ答えを入力します。

■ 遊び方
・ひとりで練習：好きなだけ問題を解けます（オフラインでも遊べます）
・友だちと対戦：部屋を立てて5桁の部屋番号を伝えるだけ。アカウント登録は不要です
・答え方は「ひらがな4択」か「音声入力」から選べます

■ 1200問以上の問題
漫画・アニメ・ゲーム、地理、歴史、科学、ことば、スポーツ、食べ物など、幅広いジャンルから出題します。
難しいヒントから順に読み上げていくので、知識が深いほど早く押せます。

■ 成績の記録
・全体とジャンル別の正答率
・問題文の何%まで出たところで押したか
・対戦の結果でレーティングが変わり、C・B・A・Sのランクが上がっていきます

■ 問題の投稿
自分で作った問題を投稿できます。文法を整えたうえで出題に加えます。
よくない問題だと思ったら👎で知らせることもできます。
```

## コンテンツのレーティング（IARC アンケート）の答え方（下書き）

- カテゴリ：ゲーム
- 暴力・性的表現・ギャンブル・薬物・下品な言葉：すべて「いいえ」
- ユーザー同士のやり取り：「はい」（対戦相手の名前が表示される。チャットはない）
- ユーザー作成コンテンツ：「はい」（問題の投稿。運営が確認してから掲載する）
- 位置情報の共有：「いいえ」／デジタル商品の購入：「いいえ」

## データセーフティ（データの安全性）の答え方（下書き・Claudeの解釈を含む）

- データを収集または共有するか：**はい**
  - 収集するデータ：「アプリのアクティビティ ＞ その他のユーザー作成コンテンツ」（投稿された問題と任意の投稿者名）
    - 任意（投稿機能を使った人だけ）／目的：アプリの機能／第三者と共有しない
  - 音声：文字起こしは端末のブラウザ（Google の音声認識）が行い、アプリ運営者は受け取らない → アプリとしては「収集しない」と判断（解釈）
  - 対戦の接続仲介（PeerJS の公開サーバー）で IP アドレスがやり取りされる → 一時的な通信処理で保存しないため「収集」には当たらないと判断（解釈。心配なら「デバイスなどの ID」を申告する）
- 送信時の暗号化：はい（HTTPS）
- データの削除リクエスト：GitHub の Issues で受け付ける
- 広告：なし／アカウント作成：なし

## 対象年齢

- 対象年齢は「13歳以上」を選ぶ（子ども向けとして申請すると「ファミリー ポリシー」の追加審査がある）。

## 本人がやること（Claude は代われない）

1. Google Play Console で**個人の開発者アカウントを作る**（登録料 25 ドル・本人確認）
2. **クローズドテストのテスターを12人以上集める**（Googleアカウントのメールアドレス）。12人が14日間続けて参加していないと、一般公開を申請できない
3. ストアの掲載情報・レーティング・データセーフティを Play Console で入力する（上の下書きを使う）

## アプリ本体（2026-11-27 作成済み）

- PWABuilder で作成。パッケージ名 `io.github.al00000000.hayaoshiquiz`、バージョン 1.0.0.0（versionCode 1）。
- .aab と署名鍵は **このリポジトリには置かない**（PCの非公開フォルダに保管。手順もそこにある）。
- サイトとアプリのひも付け（assetlinks.json）は、リポジトリ `AL00000000.github.io` の `.well-known/` に配置済み。Google の確認APIでも認識されている。
  Play にアップロードしたあと、Play のアプリ署名鍵の SHA-256 を追加する必要がある。
