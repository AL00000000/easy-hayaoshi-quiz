# easy-hayaoshi-quiz

早押しクイズの勉強をしたことがない人でも遊べる早押しクイズ。サーバー不要の静的サイト（GitHub Pages）。

- 問題文は1文字ずつ流れ、読み上げもできる。クリックかスペースキーで早押し。
- 答え方：ひらがな4択（1〜4キー可・途中で違う文字を選んだら不正解）／音声入力（認識結果を確認して Enter。Chrome・Edge のみ。手で直すこともできる）。
- 出題方式：方式1（最初に押した1人だけ）／方式2（押した順に、部屋の人数×◯％の人数まで。4択のみ）。
- 対戦はホストのブラウザが審判役になり、PeerJS（WebRTC。公開のシグナリングサーバーを使用）でつなぐ。部屋番号5桁で参加。
- 早押しの順番は「各自の画面で問題文が流れ始めてから押すまでの時間」で比べる（通信の遅れで不利にならないように）。

## データ
- `questions.js` に問題。`reading` が4択の正解、`accept` が音声入力で正解にする別名（例：宮島 → 厳島）。`tts` は読み上げ用の文（Cr→シー・アールなど、略号が答えとして読まれるのを防ぐ）。
- 正答率・ランク別正答率・ブーイング（正解者/不正解者/未解答）・問題レーティングは **その端末の localStorage** に保存（共有サーバーなし）。

## 公開
main ブランチのルートを GitHub Pages で配信。

## 投稿の取り込み（手動・Claude Code）

1. サイトの「問題を投稿する」から送られた問題は、Googleフォーム「簡単早押しクイズ 問題投稿」（alzahs000 アカウント）の回答に入る。
2. 「投稿を整形して」と頼まれたら、フォームの回答を読み、`data/07_user.txt` の最後の「# 投稿:」より新しいものだけを処理する。`【テスト】` で始まる投稿は無視する。
3. 整形は文法の訂正だけ（内容・ヒントの順番は変えない）。事実の誤りや答えが一つに決まらないものは取り込まず、本人に一覧で報告する。
4. `data/07_user.txt` の末尾に `# 投稿: 日時 / 投稿者名` と問題の行を足し、`python tools/build_questions.py` → コミット → push。
